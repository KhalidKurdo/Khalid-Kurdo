ڕێنمایی تۆڕ — DNS

ڕاژەکانی DNS بۆ خێراکردنی ئینتەرنێت و بلۆککردنی ڕیکلام

کۆمەڵێک لە متمانەپێکراوترین ڕاژەکانی DNS ی بەخۆڕایی لە جیهاندا، دابەشکراون بەپێی مەبەست. کلیک لەسەر هەر ناونیشانێک بکە بۆ کۆپیکردنی ڕاستەوخۆی، پاشان ڕێنماییەکانی چالاککردن لە خوارەوەی پەڕەکە بۆ ئەندرۆید و ئایفۆن بەکاربهێنە.

چۆن DNS لەسەر مۆبایلەکەت چالاک بکەیت

شێوازی نوێ (Private DNS / DoH) لەگەڵ ناونیشانە نووسراوەکان وەک dns.quad9.net بەکاردێت، بەڵام ناونیشانە ژمارەییەکان وەک 1.1.1.1 لە ڕێکخستنی دەستیی Wi-Fi بەکاردێن.

🤖 ئەندرۆید

پشتگیری Private DNS لە Android 9 و سەرەوە هەیە (لەسەر هەموو تۆڕەکان کاردەکات، نەک تەنها Wi-Fi ی ئێستا).

  1. ڕێکخستنەکان بکەرەوە، پاشان تۆڕ و ئینتەرنێت (Network & internet).
  2. DNS تایبەت هەڵبژێرە (Private DNS).
  3. ناوی هۆستی دابینکەری DNS تایبەت هەڵبژێرە (Private DNS provider hostname).
  4. ناونیشانێکی نووسراو لە لیستەکە بنووسە، وەک dns.adguard-dns.com.
  5. پاشەکەوتی بکە. بەخۆکار لەسەر هەموو تۆڕەکانی پەیوەندیدار کاردەکات.
بۆ ناونیشانێکی ژمارەیی (وەک 1.1.1.1) لە جیاتی Private DNS: دەست بگرە بەسەر ناوی تۆڕی Wi-Fi ی پەیوەستکراو ← دەستکاریکردنی تۆڕ ← بژاردە پێشکەوتووەکان ← لە DHCP بۆ Static بگۆڕە ← DNS 1 و DNS 2 بنووسە.

🍎 ئایفۆن

بۆ چالاککردنی تەواوی DoH/DoT لەسەر iOS باشترە بەرنامەی دابینکەر دابمەزرێنیت (وەک AdGuard یان NextDNS)، چونکە بەخۆکار پەڕگەی ڕێکخستن (Profile) دروستدەکات.

  1. بەرنامەی دابینکەر لە App Store دابگرە (نموونە: AdGuard، NextDNS، Quad9).
  2. بەرنامەکە بکەرەوە و لە ناوییەوە DNS تایبەت چالاک بکە — داوات لێدەکات پەڕگەی ڕێکخستنێک دابمەزرێنیت.
  3. بڕۆ بۆ ڕێکخستنەکان ← گشتی ← VPN و بەڕێوەبردنی ئامێر و ڕازی بە دامەزراندنی پەڕگەکە بە.
  4. بۆ شێوازی دەستیی لە جیاتی بەرنامەکە: ڕێکخستنەکان ← Wi-Fi ← کرتە لەسەر (ⓘ) لەتەنیشت تۆڕەکە بکە ← ڕێکخستنی DNS ← دەستیی ← ناونیشانی ژمارەیی زیاد بکە.
شێوازی دەستیی لە ڕێگەی Wi-Fi تەنها لەسەر ئەو تۆڕە کاردەکات، بەڵام پەڕگەی ڕێکخستن (Profile) لەسەر هەموو تۆڕەکان و تۆڕی مۆبایلیش کاردەکات.
بەهاکان کۆکراونەتەوە لە سەرچاوە فەرمییەکانی دابینکەران و ماڵپەڕە تەکنەلۆژی متمانەپێکراوەکان. هەمیشە پێش بەکارهێنانی بەردەوام لە ماڵپەڕی فەرمی دابینکەر دڵنیابەرەوە.
